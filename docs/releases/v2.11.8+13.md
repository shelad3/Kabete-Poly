# v2.11.8+13

KNP Management System — release notes.

## New — Notes Library (Explore)
- A dedicated **Notes Library** with **44 teaching materials** already loaded:
  Analogue/Basic/Digital Electronics, Bells & Alarms, Electrical Machines,
  Engineering Drawing, Control Systems, Communication Skills, Solar PV, CAD
  e-books, CDACC exam notices & timetables.
- **Subject filter chips**, class-scoped filtering, and file-type icons.
- **Teachers/Officials can upload new materials** (PDF, DOC, XLS, PPT) straight
  from the library screen.
- Materials are hosted on Cloudinary and readable by every user.

## New — In-app PDF reader
- PDFs now open **inside the app** instead of the external browser/app — faster,
  and immune to external viewer issues.
- Non-PDF files still open with the normal external app.

## New — Access Control (Admin)
- **Block / Restrict Users**: search any account and set status
  **Active / Restricted / Banned** via a bottom-sheet (persists to Firestore —
  admin updates are now allowed by the hardened rules).
- **Access Control screen**: global switches for **login** and **registration**
  plus allowed-role lists per action.
- Guardrails applied through the app (feature-gated tabs/screens).

## Fixed — Notifications to the Android system tray
- The app **did not request the Android 13+ `POST_NOTIFICATIONS` runtime
  permission** and created no notification channels, so reminders were silently
  dropped before reaching the status bar / lock screen.
- Now: permission is requested on startup, channels
  (`class_reminders`, `push_notifications`, `apk_downloads`) are created, and the
  manifest declares `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED` and the
  scheduled/boot receivers. Class reminders (20 min before class) and alerts now
  appear as real system notifications.

## Also in this build
- **Exam timetable**: 218 entries loaded for the Electrical department formative
  assessments (29 Sep – 2 Oct 2026) across 31 class cohorts.
- **GPA tracker** added in Grades.
- Feature flags expanded (timeline, exam timetable, school ID card, my devices,
  notes library, admin/explore/settings tabs) — all live in Firestore.
- Firestore rules updated + deployed: admin status updates, teaching materials,
  access control.

## Notes
- APK ~68 MB, Android 6.0+.
- In-app update auto-detects this build via Firestore `app_updates/latest`.
